# Asset sources and licenses

## EventCast identity and photography

The website uses EventCast Maldives' original logo, event photographs, social posts and broadcast previews. Exact original source links and attribution are stored with the content in `src/content.json` and `src/projects.ts`.

Official channels:

- [Facebook — eventcastmv](https://www.facebook.com/eventcastmv)
- [Instagram — eventcastmv](https://www.instagram.com/eventcastmv/)
- [YouTube — EventCastMaldives](https://www.youtube.com/@EventCastMaldives)

The Hiyala alternate hover image comes from the same verified production post as the cover. Display crops are presentation choices; gallery views and original source links preserve access to context. Photo publication dates do not establish capture dates.

The logo remains an original raster. SVG color/alpha filters render white or EventCast-red artwork without changing its proportions. No replacement vector master is implied.

Media attribution does not grant an open-media license. Preserve brand attribution and the original source records when collaborating on this EventCast project.

## Active fonts

- **Plus Jakarta Sans:** self-hosted Latin and Latin-ext WOFF2 subsets. [Project](https://github.com/tokotype/PlusJakartaSans). License: `public/assets/fonts/PlusJakartaSans-OFL.txt` (SIL Open Font License 1.1).
- **Noto Sans Thaana:** self-hosted weights 400, 500 and 600. [Project](https://github.com/notofonts/thaana). License: `public/assets/fonts/notosansthaana-OFL.txt` (SIL Open Font License 1.1).

Preserve the included font licenses. The unused historical Satoshi font is excluded from this repository; the current interface does not use it.
